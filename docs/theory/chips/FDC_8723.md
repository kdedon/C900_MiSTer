# MOS 8723 floppy controller (U204) and the 6508 floppy section

The "Z8000 Floppy disk controller", Commodore 315017-01, a 48-pin DIP
at U204 on motherboard sheet 14. With the 6508 (U201, sheet 13), its
8 KB firmware EPROM (U203, 0xE000-0xFFFF), the U202 74LS245 onto the
OMAD bus and the analog read/write hybrids (sheets 15-16) it forms the
floppy section. Sources: MOS drawing 315017 (reprinted in "CBM900
special chips"), the C900 Floppy Specification, sheets 13-16, and the
6508 ROM (addresses below are ROM addresses).

Legend: SOURCED / INFERRED / OPEN as in PDMAC_8716.md. RTL:
`rtl/fdc/fdc8723.sv` (the chip), `rtl/fdc/gcr_engine.sv` (state
machine and shifters), `rtl/fdc/c900_fdc.sv` (the section),
`rtl/fdc/cpu6508.sv`, `rtl/fdc/fd_drive.sv` + `fd_*.sv` (the drives).

## 1. What it is

SOURCED (315017 sec 1): one chip holding the 6508's clock generator,
the register file the 6508 programs, a GCR encoder/decoder built from
PLAs, a 16-state bit-cell state machine that is also the data
separator, digital write precompensation, sync detect/generate, the
stepper, motor, LED and head-select outputs for two drives, and the
PCSS/PCSD master port to the 8716. SOURCED (sec 1.7, register bit M):
an MFM mode bit exists; MFM is not implemented and the firmware never
sets it.

```
            _CLK 6 MHz
                |
  6508 <-PH1/PH2- 8723 -STEP0/1, MTRON, LED, HDSEL-> 75477 / 7406 -> drives
   |   A,D,R/W     |  <-RDATA- MC3470A read amp (U212) <- head matrix U205
   |-- U203 ROM    |  -WD/NWD, WRGT, ERASE-> 7406 -> write hybrid U214
   |   /SO <-------|
   |   /IRQ <- _IREQ        |  BUFFEN, DMADIR
   |   P7   <- INTEN      U202 '245: 6508 D7:0 <-> OMAD BD7:0
                            /PCSS, /PCSD -> 8716
```

which drive/side; the core puts drive LED1 side HDSEL on RDATA.

`CLV`). The 6508's own port: $00 DDR, $01 data; only P7 is wired (INTEN
from CN9 34), sampled at IRQ entry (e130).

## 4. The bit-cell state machine

SOURCED (sec 1.5, 1.8, Figures 3 and 4): 16 states per cell at 6 MHz;
faster zones skip states 3 (GG 01), 3 and 13 (GG 10), 3, 5 and 13 (GG
11), from the arc labels of the figures. Read: an RDATA pulse is
expected near state 8; an early or late pulse jumps the state toward 8,
by more the further away it lands. That is the whole data separator.
State 15 clocks the data latch into the 10-bit shifter. Ten ones in the
shifter are sync and hold the divide-by-10 counter clear; otherwise
every tenth bit decodes two quintets into the read latch and fires BRDY
(pulses /SO; 0x4007 bit 0). Write: WD toggles in state 8 of a 1-cell,
or in 7 or 9 when precompensation (0x4007 bit 1) shifts it for the
neighbouring bits; no external delay line. Sync generate (0x4002 bit 7)
forces the PLA outputs High except bits 7 and 2, which pass data bits 6
and 2 (sec 1.5); with no byte pending the shifter streams ones.

INFERRED (`fdc8723.sv` header): /SO Low from BRDY through the next PH2
rise, because the 6508 samples S.O. at the trailing edge of phi1 and the
drawing gives no width. OPEN: the real width.

GCR code (sec 1.5), nibble -> quintet:

| 0 01010 | 1 01011 | 2 10010 | 3 10011 | 4 01110 | 5 01111 | 6 10110 | 7 10111 |
|---|---|---|---|---|---|---|---|
| 8 01001 | 9 11001 | A 11010 | B 11011 | C 01101 | D 11101 | E 11110 | F 10101 |

## 5. On-disk format

SOURCED (Floppy Specification sec 3.1; CMD_FORMAT e436), one stream
byte = 10 recorded bits:

```
SYNC 4 x FF | 08 | CYL | SEC | XOR     ID field (XOR of 08, CYL, SEC)
GAP1 14 x 00
SYNC 4 x FF | 07 | 512 data | XOR      data field
GAP2 G x 00                              540 + G bytes per sector
```

CYL carries parity in bit 7, SEC in bit 4. Sectors run in order from
the revolution origin; the last gap runs to the origin (no index: the
firmware finds sector 0 by reading IDs). G is set by the format's speed
check (CalibrateSpeed e588): write a track of 00, write sync, count the
bytes until the sync comes round, then G = 16 + (count - K) / sectors
with K = 8908, 8352, 7794, 7238 per zone (tables e675/e679); minimum 12
for a 2 % fast drive.

Stepper (table e80a: 05, 06, 0A, 09): full-step two-phase; one table
step per track, about 4 ms between steps (delay_6000 = 6020 cycles at
1.5 MHz); recalibrate steps out until the track-0 bit.

## 6. Firmware behaviour (6508 ROM, U203)

SOURCED (ROM listing). Reset: RAM test (e028), DDR = 0x40, idle loop
e0d7-e0f7 (CLI, motor timeout, no 8716 access). IRQ (vector fffe ->
e14d): resets the stack (a command in flight is abandoned), sends 0x9F
(IRQ_HIGH), waits for INTEN High (e130; the 8049's not-my-command
window), then fetches the sentinel word at byte +0x1C of its command
block (0x080010) with a single-step DMA. 0xFF there means "not armed":
back to idle. Otherwise it reads the 16-byte block and dispatches
(table e28a):

| Opcode | Command | Handler |
|--------|---------|---------|
| 0x04 | FORMAT | e436 |
| 0x08 | READ | e2a6 |
| 0x0A | WRITE | e32c |
| 0x0F | MOVCMD | e8fb |
| 0xE3 | FILL | e8ce |
| 0xDE | GOTO | e8b0 |

Command block (Coherent `wd.c` WDCMD, "SASI-like"): +0 opcode, +1 LUN
and address bits 20:16, +2/+3 sector address, +4 block count, +5
control, +6/+7/+8 DMA address (segment, middle, low), +0xC errorbits
(0xFF = armed; the result replaces it), +0xD..0xF error address. The
whole command runs with I set; a new _IREQ is taken only back in idle.

DMA use: `DMA_Rd_Addr`/`DMA_Wr_Addr` (e244/e247) send 0x7F, LD2 with
the rotated address (carry = DIR), LD1; `DMA_Single` (e264) 0x7F, 0xDE,
word address, then `DMA_Start` (e278) polls Rd_Status until BYTERDY and
sends 0xF7. A sector read is one `EOR 0x4005` per byte: read the GCR
byte, fold it into the checksum and push it to the 8716 in one 6508
instruction. Completion (Error_A e197): write (code, unit) at +0x1C and
the failing block at +0x1E by single steps, park the address latch
(LD2 data 0xFF, 0xFF), then 0xBF (/VI). The BIOS and kernel read
errorbits: 0x80 = done, else an error (0x91-0x9F seen; 0x92 = no sync
after two sweeps and a recalibrate, about 1 s).

Sharing with the HDC: see PDMAC_8716.md section 7.

## 7. Timing the software relies on

- SOURCED: 6508 at 1.5 MHz from PH2; one byte per 21.7-26.7 us, so the
  read loop has 32-40 cycles per byte for checksum, PCSD and the BVC
  poll.
- SOURCED (sec 1.3.4): RDATA pulse about 250 ns, synchronised to CLKIN.
- INFERRED (DECISIONS D-FDC-1): the 8723 select is the window decode
  qualified by PH2 High; a write commits at the select rise, read data
  is taken at the PH2 fall. The drawing gives the register map, not
  the bus timing.
- Motor: 300 RPM, 200 ms per revolution (Floppy Specification).

## 8. How we learned it

- Drawing 315017 (Pleban scan pp. 30-36): pins, registers, Figures 3-4.
- Sheets 13-16 (Pleban pp. 150-151, 74-77) for the nets, read twice.
- Floppy Specification sec 2-3: format, sharing, the /SO note.

  constants, GAP2 calibration.
- Coherent `drv/wd.c` for the command block and NFBLK.
- The simulator boots Coherent from floppy with this model; the RTL
  replays its vectors and runs the floppy probe clock-exact against it
  (DECISIONS D-FDC-2).
